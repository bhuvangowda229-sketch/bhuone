Project Synopsis

AI-Based Interior Design Suggester with 3D Visualization

This project involves developing an intelligent web application that simplifies interior design planning by providing personalized design suggestions and interactive 3D visualizations. Users input room details such as type, dimensions, preferred style, colors, flooring, and lighting preferences. The system uses AI to generate tailored recommendations for furniture, color schemes, lighting setups, and spatial arrangements.

AI-Driven Suggestions: Tailored furniture selection, color harmony palettes, and spatial layouts.

Questions

Frequently Asked Questions

Everything you need to know about the AI Interior Design Suggester.

Do I need a graphics card or heavy software to run this?
No! The application runs completely in any modern web browser (Chrome, Edge, Safari, Firefox) utilizing lightweight procedural WebGL/Three.js geometry.
Does the AI engine require an external API key?
No! It comes with a built-in algorithmic AI spatial planning engine that computes ideal clearances, focal points, and layouts instantly offline. You can also optionally connect a Google Gemini API key for live generative descriptions.
Can I modify furniture placements manually?
Yes! In the 3D Studio, simply click any piece of furniture to bring up the inspector, where you can reposition, rotate by 45°, change color finishes, or delete items.
How do I save or share my designs?
You can save designs directly in your browser's local storage, export them as lightweight JSON files to share with friends or contractors, and capture high-resolution 3D snapshot images (.png).
